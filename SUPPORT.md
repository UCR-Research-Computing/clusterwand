# Getting help

- **Connecting to your cluster** (keys, jump hosts, MFA): see [docs/SSH.md](docs/SSH.md).
  Access to the cluster itself is your site's business: ask its administrators.
- **Connecting a client**: start with [docs/CLIENTS.md](docs/CLIENTS.md), which has a
  troubleshooting table.
- **A bug or a wrong diagnosis**: open an issue with the bug form. Include
  `clusterwand version`, the command or tool call, and the `--json` output (remove anything
  private).
- **An idea**: open an issue with the feature form.
- **A security problem**: see [SECURITY.md](SECURITY.md); please don't open a public issue.
